# where-so — Lọc dòng với WHERE; so sánh số {trang sổ: where-so}

<!-- QĐ-092: bài số đi trước bài chữ. Trang chị Linh là kiến thức SQL (phiên logic giữ); lời Hà Vy phiên truyện được viết lại. -->

- Loại: cú pháp

## Trang chị Linh
Muốn lấy những dòng thỏa một điều kiện thì thêm WHERE: `WHERE cột = giá trị`.
Số thì viết đúng như dữ liệu đang lưu: cột khóa lưu `2024` thì viết `khoa_hoc = 2024`, không phải "K24".

## Hà Vy
- **ha-vy** (thinking): Trước khi lọc, nhìn xem cột ấy thật ra đang lưu cái gì đã.

## Vào sổ cá nhân
- Chú thích: Lọc dòng: `WHERE cột = giá trị`. Số thì viết đúng như dữ liệu đang lưu: `khoa_hoc = 2024`.
